# Black PIC v2

零依赖的手机相机 Web 交互原型，使用原生 JavaScript、CSS 和 WebGL。支持 AI 一键出图、个人灵感库、实时影调、拍摄与本地作品管理。桌面浏览器中显示手机外壳，手机浏览器中全屏显示。

## 本地运行

需要 Node.js 18 或更高版本，无需安装依赖。在项目目录运行：

```bash
npm run dev
```

打开 [本地预览](http://localhost:4175)。端口占用时可用 `PORT=4176 npm run dev`。页面使用 ES modules，需要通过 HTTP 服务访问；图片和样式均为本地资源。

## 体验流程

- 进入相机会显示内置取景。左上角「…」可以连接摄像头、导入取景照片或视频，以及切换「演示起点」。首次进入取景时，取景画面下方会出现指向右下「灵感」入口的可关闭提示。
- 底部可切换「照片 / 视频 / Live」。三种模式点 **AI** 都会显示「识别场景 → 匹配偏好 → 套用」，将偏好效果应用到实时取景。空库、无匹配或识别失败时使用默认效果。
- 点拍摄模式行右侧的「换效果」可实时切换四款滤镜或原生色彩，并调整强度。关闭面板、往返图库或切换拍摄模式时保留当前效果。切换取景来源会恢复原生色彩。点对比按钮显示原片和角标，再点一次恢复当前效果。
- 快门保存所见画面。照片直接保存当前帧，视频按快门开始和结束，Live 约三秒后自动结束。AI 和手动调节都在取景页完成，作品只通过快门生成。
- **灵感库**提供可折叠的内置示例和我的上传。上传的照片会自动提取指纹，应在「我的上传」中长按一张进入选择模式，再多选删除。删除上传会同步移除对应指纹，示例仅供参考。
- **作品集**按拍摄时间倒序排列。详情可查看、播放、保存或确认删除，列表可长按进入选择模式并多选删除。

## 实现边界

- 内置取景使用预设场景标签。导入图和实时相机以小尺寸像素采样提取主色、亮度和反差，按同场景挑选一张上传指纹并应用对应效果。
- 作品、上传图片、指纹和已有手动配方存入 IndexedDB。取景提示的展示记录存入 localStorage。数据按浏览器和站点地址区分。
- 视频录制无音轨。Live 保存为照片与独立短视频，作品详情可分别下载。

## 代码结构

| 文件 | 用途 |
| --- | --- |
| `index.html`、`*.css` | 页面结构、手机布局与交互样式 |
| `app.js` | 相机状态、拍摄、配方和本地存储 |
| `core.js`、`interaction-core.js` | 参数、LUT 解析与交互计算 |
| `renderer.js` | WebGL 实时渲染 |
| `camera-interactions.js` | AI 三步反馈、变焦手势和配方长按交互 |
| `experience-model.js`、`personal-style.js` | 审美指纹提取、场景匹配和灵感库 |
| `assets/` | 运行所需图片、示例 LUT 与素材来源说明 |
| `server.mjs` | 本地静态服务器 |
| `tests/` | 单元测试与浏览器回归测试 |
| `scripts/record-demo.mjs` | 浏览器演示录屏脚本 |

## 检查

```bash
npm run check
npm test
```

浏览器回归需要 Node.js 22+ 和开启本机调试端口的 Chrome。请使用独立的 Chrome 测试配置目录：测试会清空该浏览器中的演示站点数据。保持本地服务运行后执行：

```bash
npm run test:browser
```

默认连接 `http://127.0.0.1:9227`，演示地址为 `http://localhost:4175/`；可通过 `CAMERA_CDP_ENDPOINT` 和 `CAMERA_DEMO_URL` 覆盖。测试包含三模式 AI、取景效果调节、点击对比、视频和 Live 录制回放、上传指纹匹配、长按多选删除、取景中断恢复以及不同屏幕尺寸，截图自动写入 `previews/`。

录屏脚本复用相同的浏览器配置，另需 `/opt/homebrew/bin/ffmpeg`，可运行 `node scripts/record-demo.mjs`。输出位于 `recordings/`。

`previews/`、`recordings/`、缓存、日志和本地环境配置均由 `.gitignore` 排除，不需要提交到 GitHub。素材出处见 [素材来源说明](./assets/来源说明.md)。
