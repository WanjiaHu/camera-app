# 演示素材

以下三张素材从 `261108产品方案.pptx` 第 13 页原样提取，没有修改原始图片文件。PPT 仅作为出处记录，不是运行依赖，也不包含在代码目录中。

| 文件 | PPT 内的媒体 | 用途 |
| --- | --- | --- |
| reference-blue-water.jpg | ppt/media/image23.jpeg | 用户喜欢的通透蓝绿、大面积水面参考 |
| reference-water-light.jpg | ppt/media/image24.jpeg | 水光与颜色层次参考 |
| harbor-original.jpg | ppt/media/image25.jpeg | 当前现场的原始画面，用于实时渲染、数字取景和前后对比 |

`harbor.jpg` 为此前已有的处理后示例，只供其他图库样例引用。新的海港相机预览始终以 `harbor-original.jpg` 为源，不用已有成片冒充实时处理输出。

`coast.jpg`、`coast-cliffs.jpg` 沿用上一版素材。根据上一版 README 记录，来源分别为 Unsplash 的 [海岸小镇](https://images.unsplash.com/photo-1689413055036-545ee2e9470c) 和 [悬崖与海浪](https://unsplash.com/photos/a-small-village-on-the-side-of-a-cliff-next-to-the-ocean-JXwr2jJKiKY)。图像线索与现场条件使用预设，用于展示交互主线。

`luma-warm-demo.cube` 是用于手动验证 LUT 导入的暖色示例。
